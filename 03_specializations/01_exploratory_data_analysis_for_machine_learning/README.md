# Exploratory Data Analysis for Machine Learning

The notes in this folder are curated from my studies of the course [Exploratory Data Analysis for Machine Learning](https://www.coursera.org/learn/ibm-exploratory-data-analysis-for-machine-learning) by **IBM**, available on Coursera.

## How to Use These Notes

The best way to benefit from these notes is to take the course and use them as reminders of the main ideas and techniques. Alternatively, you can use these notes as prompts for AI agents (such as ChatGPT or GitHub Copilot) to request more detailed explanations or code examples on specific topics.

### Prerequisites

To get the most out of this section, it is highly recommended to first complete the foundational modules in this repository:
- **[Math](./../../01_math/)**: A solid understanding of statistics is essential for interpreting EDA results.
- **[Toolkit](./../../02_toolkit/)**: Proficiency with Pandas for data manipulation and Matplotlib/Seaborn for visualization is assumed.

The notes and code examples here are intentionally kept brief to avoid repeating the fundamental concepts covered in the prerequisite sections.
