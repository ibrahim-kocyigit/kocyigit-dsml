# Machine Learning Model Lifecycle

## Processes in the Lifecycle

The Machine Learning Model Lifecycle consists of the following key processes:

- **Problem Definition** - Stating the situation or business problem
- **Data Collection** - Gathering relevant data from various sources
- **Data Preparation** - Cleaning, transforming, and preparing the data
- **Model Development & Evaluation** - Building and testing the machine learning model
- **Model Deployment** - Putting the model into production use

## Key Characteristics

### Iterative Nature
The model lifecycle is **iterative** - teams frequently go back and forth between processes. For example:
- If problems are found with deployed models in production
- You may need to return to data collection or even problem definition
- Then re-iterate through subsequent processes

### ETL Process
Data collection and preparation together form the **Extract, Transform, and Load (ETL)** process:
- **Extract**: Collecting data from various sources
- **Transform**: Cleaning and transforming the data
- **Load**: Storing processed data in a new single location

This prepared data then becomes accessible for machine learning engineers to build models.

## Summary

The Machine Learning Model Lifecycle involves five main processes that work in an iterative manner, with data preparation occurring through the ETL (Extract, Transform, Load) methodology.
