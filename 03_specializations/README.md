# Specializations: From Analysis to Prediction

This pillar is where the Math and Toolkit foundations come together and are applied to real-world problems. Each specialization is a deep dive into a specific domain — statistical modeling, machine learning, and (upcoming) deep learning — building progressively from inference to prediction to representation learning.

## The Learning Arc

The three specializations follow a deliberate sequence:

1. **Statistical Modeling** teaches you to understand data — to quantify relationships, test hypotheses, and draw reliable conclusions. This is the foundation of data science: *explaining* what's happening.

2. **Machine Learning** teaches you to predict from data — to build models that generalize to unseen inputs, evaluate them rigorously, and select the right algorithm for a given problem. This is the foundation of applied ML: *predicting* what will happen.

3. **Deep Learning** (scheduled for Q3 2026) will teach you to learn representations from data — to work with neural networks, unstructured data (images, text), and the architectures that power modern AI.

Together, these three specializations cover the core competencies a data scientist needs to tackle most real-world problems.

## Current Priority

The first two specializations — Statistical Modeling and Machine Learning — are complete. They provide enough depth to tackle freelance data science projects end-to-end: from exploratory analysis and statistical inference through building, evaluating, and deploying predictive models (see the [MLOps](../04_mlops/) pillar for the deployment side).

Deep Learning is intentionally deferred to **Q3 2026**. My current focus is on applying the knowledge already consolidated in this repository to generate real-world freelance data science projects. The fundamentals covered in pillars 01 through 04 are more than sufficient for the vast majority of tabular data, business analytics, and classical ML projects that make up the freelance market. Deep learning will be added when the time is right.

## Specializations

### [01 — Fitting Statistical Models to Data with Python](./01_fitting_statistical_models_to_data_with_python/)

Personal lecture notes and Jupyter Notebooks from the [Fitting Statistical Models to Data with Python](https://www.coursera.org/learn/fitting-statistical-models-data-python) course by the **University of Michigan** on Coursera.

| Section | Topics |
| :--- | :--- |
| Considerations for Statistical Modeling | Study design, data types, assumptions, choosing the right model |
| Fitting Models to Independent Data | Distribution fitting, parameter estimation, goodness-of-fit |
| Fitting Models to Dependent Data | Linear regression, logistic regression, model interpretation |
| Special Topics | Multilevel models, Bayesian approaches, advanced techniques |

### [02 — Machine Learning with Python](./02_machine_learning_with_python/)

Personal lecture notes and Jupyter Notebooks from the [Machine Learning with Python](https://www.coursera.org/learn/machine-learning-with-python/) course by **IBM** on Coursera.

| Section | Topics |
| :--- | :--- |
| Introduction to Machine Learning | Supervised vs. unsupervised learning, the ML workflow |
| Linear and Logistic Regression | Linear regression, logistic regression, regularization |
| Non-Linear and Ensemble Models | Decision trees, random forests, gradient boosting (XGBoost), SVMs, KNN |
| Building Unsupervised Learning Models | K-means clustering, hierarchical clustering, DBSCAN, PCA |
| Evaluating and Validating Models | Cross-validation, confusion matrix, ROC/AUC, bias-variance tradeoff |
| Final Project | End-to-end classification project applying the full ML workflow |
